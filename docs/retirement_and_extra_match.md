# リタイア・追加対戦・進行枠の差し替え

リーグでリタイアが出たときの3つの機能の説明です。
マニュアル作成とレビューのための資料です。

- リタイア
- 追加対戦
- 進行枠の差し替え

既存機能は 2026-10-16 時点のコード(`3330090`)で確認しました。追加試合の編集・削除の説明は 2026-10-17 に追記しました。2026-10-16 の確認時点で、実データに差し替え履歴は1件もありません。

## 全体の流れ(例)

リーグに A・B・C・D の4ペアがいて、B が途中でリタイアした場合です。

| 段階 | 運営者の操作 | システムの動き |
|---|---|---|
| 1. リタイア | B を「リタイアにする」 | B の未入力の試合(例: B対D)が、相手の不戦勝として自動で埋まる。B対D の進行枠は「終了」になる。 |
| 2. 追加対戦 | 空いた時間に「A対C 2回目」を作り、B対D があった進行枠を指定する | B対D の進行枠が A対C 2回目 に置き換わる。これが「差し替え」で、元に戻すための履歴が残る。 |
| 3. 取り消し(必要なら) | 「差し替えを取り消す」 | A対C 2回目 を削除し、進行枠を B対D に戻す。 |

差し替えは、リタイアで消化不要になった進行枠を、別の試合に使い回すための機能です。

## 1. リタイア(リーグ)

**入口:** 参加者名簿 / リーグ枠一覧の各枠にある「棄権」から「リーグ枠棄権」画面を開き、「リタイアにする」を押します。

**システムの動き:**
- その枠の試合のうち、**スコアが未入力の試合だけ**を、相手の勝ちとして埋めます。スコアは、相手が勝ちに必要なゲーム数、リタイア側が 0 です。この試合は「リタイアによる不戦」という種類になります。
- すでに結果が入っている試合はそのまま残します。
- 埋めた試合の進行枠は、呼出・開始・終了がすべて済んだ状態になります。
- リーグ順位を計算し直します。

**取り消し:** 同じ画面の「リタイアを取り消す」で取り消せます。
- 自動で埋めた不戦結果を、未入力に戻します。
  - ただし、相手もリタイアしている試合は、取り消した側の不戦勝として付け直します。
- 自分で入力した結果はそのまま残します。
- 順位と、後続Stageへの進出を計算し直します。
- その枠の不戦試合の進行枠が、追加対戦に差し替えられたままのときは、**取り消せません**。先に差し替えを取り消す必要があります。

## 2. 追加対戦

**入口:** 各リーグにある「追加対戦」です。次の2つの画面にあります。
- 横断表示(Stage進行/横断表示)
- カテゴリ詳細(リーグ表)。ただしこの画面はメニューからたどれません。「棄権」画面の「リーグ表へ戻る」や、リタイアなどの操作のあとに移る先として開くだけです。

作った後は、次の操作ができます。
- 結果の入力: 「追加試合」の表の対戦名から
- 進行表での移動・外す・配置: 日程区分の詳細画面から。ふつうの試合と同じ扱いです。
- 「順位計算に含める」・理由の変更: 「追加試合」の表の「編集」から。順位計算の対象を切り替えると、順位を計算し直し、後続Stageへの進出を自動反映します。理由だけの変更では順位を変えません。
- 試合そのものの削除: 同じ編集画面から。**2回目以降の追加対戦で、結果がなく、呼出・開始・終了のいずれにもなっていない試合だけ**削除できます。結果がある場合は先に結果を削除してください。
  - 差し替えで入っている場合は、元の不戦試合と進行状態に戻します。
  - 通常の挿入で入っている場合は、進行枠から外し、同じ日程区分・コートの後ろの試合を1つずつ前に詰めます。
  - 削除後に順位を再計算し、後続Stageへの進出を自動反映します。

**入力項目:**

| 項目 | 意味 |
|---|---|
| 対戦枠1・対戦枠2 | 同じリーグの2枠。リタイア済みの枠は選べない。 |
| 順位計算に含める | 初期値はオン。オフにすると、試合は行うが順位計算には使わない。 |
| 理由 | 初期値は「リタイアに伴う追加対戦」 |
| 進行表へ追加する | 初期値はオン。オンにすると、下の3項目で指定した位置に入れる。 |
| 日程区分・コート・挿入位置 | 進行表のどこに入れるか |

- 同じ2枠が既に対戦していれば「2回目」「3回目」として作られます。
- 作った試合は、リーグ表の「追加試合」欄に出ます。

## 3. 進行表への入れ方: 差し替えと挿入

「進行表へ追加する」をオンにしたとき、指定した位置にある試合によって動きが変わります。

| 指定した位置にある試合 | 動き |
|---|---|
| **リタイアによる不戦の試合** | **差し替え。** その進行枠の中身を追加対戦に置き換えます。後ろの試合はずれません。進行枠は未着手に戻り、元の試合と状態を履歴に残します。 |
| それ以外の試合、または空き | **挿入。** 指定した位置に入れ、その位置から後ろの試合を1つずつ後ろへずらします。後ろに呼出済・試合中・完了・結果入力済の試合があると、入れられません。 |

不戦の進行枠は「終了」扱いなので、普通の挿入では、その前に入れることはできません。差し替えは、この空いた枠を使うための例外です。

差し替えたあと、元の不戦試合はどの進行枠にも入っていない状態になります。不戦の結果はリーグ表に残ります。

## 4. 差し替えの取り消し

**入口:** リーグ表の各リーグに、差し替えがあるときだけ「進行枠の差し替え」という表が出ます。そこにある「差し替えを取り消す」ボタンです。

**取り消せる条件(すべて満たすこと):**
- 追加対戦が、まだ呼出・開始・終了のどれにもなっていない。
- 追加対戦に結果が入っていない。
- 差し替えたあと、その進行枠が別の操作で変わっていない。

**システムの動き:**
- 進行枠の中身を元の不戦試合に戻します。呼出・開始・終了の状態も差し替え前に戻ります。
- **追加対戦の試合そのものを削除します。**
- 履歴には「取り消し済み」の印が付きます。履歴そのものは残ります。

## 5. トーナメントのリタイア

トーナメントには、差し替えの仕組みはありません。

- 結果入力画面で、「上側リタイア」「下側リタイア」「両者リタイア」のボタンを押します。
- 片方のリタイアでは、相手を勝者として次の試合へ送ります。
- 両方リタイアでは勝者なしになり、次の試合は相手が来るのを待ちます。

## 他の機能との関係

- **リタイア取消:** 差し替えが残っていると取り消せません(上記1)。
- **結果一括削除(設計中):** 同じ理由で、差し替えが残っているStageは一括削除を止める予定です。
  - 一括削除はリタイアも解除するので、元の不戦試合は普通の未試合に戻ります。
  - しかし進行枠には追加対戦が入ったままなので、元の試合がどの枠にもなくなってしまいます。
  - 先に「差し替えを取り消す」で戻してもらう運用にします。
- **スナップショット / 大会バックアップ:** 差し替え履歴も保存・復元の対象です。

## 対応済みの問題

- 「リタイアにする」は、以前はトランザクションで囲まれておらず、後続Stageへの進出の自動反映も呼んでいませんでした。そのため、リタイアでリーグの全試合が埋まっても、後続の枠が空のままでした。
- 2026-10-17 に直しました(`b11766c`)。処理は `services/operations.py` の `retire_league_entry` に移り、1つのトランザクションの中で次のことをします。
  - 不戦結果を入れる
  - 順位を計算し直す
  - 後続Stageへ進出を反映する
- すでにリタイアの枠をもう一度リタイアにしようとすると、エラーで止まります。
