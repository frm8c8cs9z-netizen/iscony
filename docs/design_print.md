# 設計メモ: 印刷(途中結果の貼り出し)

途中結果を印刷して貼り出すための機能のメモです。2026-10-20〜21 に、2026_西日本小学生大会(2026-10-24)に向けて作りました。

## できていること

### リーグ印刷(`league_stage_print`)

横断表示のリーグStageにある「印刷」から開く。

- **操作欄:**
  - 印刷内容: リーグ表(追加試合を含む)/同率補助表のみ
  - 用紙: A4/A3
  - 向き: 縦/横
  - 1行に並べる数: 1〜6
  - 2ページ目以降のヘッダー: 出す/出さない
  - リーグを囲む枠: 既定はなし
- **並べ方:** 文字の大きさは、Stage内で共通の倍率で、枠いっぱいまで自動で拡大する。1つのリーグは、ページの境目で分けない。
- **勝・敗・順位:** 集計前は「未集計」と出さず、罫線つきの空欄にする。手書きで書き込める。

### トーナメント印刷(`tournament_stage_print`)

横断表示のトーナメントStageにある「印刷」から開く。

- 分割したトーナメントは、1ブロック=1ページにする。上位トーナメントは「別のページ」か「最後のページに一緒に」を選べる。
- 縮尺は、Stage内で1つにそろえる。「すべてを最も少ない枚数に収めたうえで、そのなかで一番大きい縮尺」にする。
- 小さなトーナメント表は、入るだけ1枚にまとめる。図は、用紙の上下左右の中央に置く。

### 共通

- ページの組み立ては、ブラウザ任せにせず、画面側で行う(`core/static/core/js/stage_print.js`)。
- **ページ番号:** 右上に、見出しと同じくらいの大きさで「n/N」と出す。
- **ヘッダー:** 1ページ目は常に出す。2ページ目以降は、出すかどうかを選べる。
- **印刷日時:** 下部に「時点」を出す。
- 色はカラーで印刷する(`print-color-adjust: exact`)。リンクやボタンは印刷しない。運営専用なので、ログインが必要。

## 後回しにしたもの(大会の後に実装する)

### 複数Stageのまとめ印刷

KENKOCUPの「２位リーグ → ２位トーナメント」のように、リーグと小さなトーナメントが1つのまとまりになっている場合に、それを1つの印刷物にまとめたい。横断表示の表示順(`Stage.display_order`)は、このまとまりを意識して組んである。

案:

- 横断表示に「まとめて印刷」を置き、Stageを選んで印刷する。
- 選んだStageの中身(リーグの表とトーナメントの図)を、横断表示の順で並べる。トーナメントと同じルールで詰める(最も少ない枚数で、一番大きい縮尺)。
- ヘッダーは大会名とカテゴリにし、各表にStage名などの小見出しを付ける。
- リーグ印刷とトーナメント印刷の「並べて詰める」処理を、1つにまとめる作り直しになる。

### その他の候補

- 大きなトーナメント(64枠など)を上下2ページに分けて印刷する。今は1ページに収めるので、A4だと字が小さい。まずはA3で運用する。
