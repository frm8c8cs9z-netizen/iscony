# グループ・トーナメント表の本部コメント

2026-11-26 作成。12/19 の大会での利用を目指す。

## 背景

実際の運営で、結果について伝えなければならないことを、グループやトーナメント表のそばに出したい場面があった。例としては次のようなもの。

- 「◯番は棄権のため、順位は…」
- 「同率のため、抽選で◯位を決定」

本部がフォームから文章を書き、目立つ表示で出せればよい。

## 決定事項

### データ

- グループ(`Group`)とトーナメント表(`TournamentBracket`)に、本部コメントを1つずつ持たせる。
  - 項目は空でもよい文章(TextField)とする。
  - マイグレーションを1つ追加する。
- 履歴は持たない。更新時刻も表示しない。
- 複数の連絡は、改行で書き分ける。改行はそのまま表示する。
- 空なら何も表示しない(枠も出さない)。

### 表示する場所

| 画面 | 表示 |
|---|---|
| 運営側の横断表示(Stage進行、`category_stage_overview`) | 出す。入力もここで行う |
| 一般公開のカテゴリ結果(`public_category_results` のトークン版) | 出す |
| 印刷(リーグ・トーナメントの Stage 印刷) | 出す |
| 進行表(運営・一般公開とも) | 出さない |

- 表示位置:
  - グループは、追加試合も含めたグループのいちばん下。
  - トーナメント表は、表のすぐ下。
- 見た目:
  - 薄いクリーム色の背景と淡い細い罫線の枠に、赤の太字の本文を置く。見出し(「本部より」)は付けない(2026-11-26、背景・罫線が強すぎるとの意見で調整)。
  - 進行状況の青い札とは、色で区別できるようにする。
  - 印刷では、白黒でも目立つように、太字と罫線の枠にする。

### 入力

- 運営側の横断表示で、各グループ・各トーナメント表の下に「本部コメント」ボタンを置く。
- ボタンを押すと、小さな入力ダイアログを開く。
  - 保存・書き換え・消去ができる。
  - 消去は、空にして保存する扱いでもよい。
- 保存したら、横断表示の同じグループ・トーナメント表の位置へ戻る。
- 書き込めるのは、運営側にログインしている人なら誰でもよい。
  - 将来、権限を分けるときは、本部側の権限にする。

### 複製・バックアップ

- 大会をコピーするとき、コメントは引き継がない。その大会限りの連絡のため。
- スナップショット・バックアップからの復元では、コメントも一緒に戻す。

## 対象外

- 履歴、更新時刻、複数件の管理。
- 進行表への表示。
- お知らせ機能(大会全体のタイムライン)とは別のもの。お知らせ機能は、別の課題として扱う。
