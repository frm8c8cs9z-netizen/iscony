# 設計メモ: 変則トーナメント(不戦の位置を指定するトーナメント表)

状態: **保留(未着手)**。2026-10-26 にユーザーと話して、対応はいったん保留にしました。対応方法は後で考えます。

## 背景: 晴れと雨で試合形式を切り替える

- 屋外の大会では、晴れの場合と雨の場合で試合の形式を変えることがよくある。**晴れならリーグ、雨ならトーナメント**に切り替えることが多い。
- 晴れ用と雨用で大会を分けて作る、今のやり方でよい(例: 2026_WESTJAPAN_ELSC と 2026_WESTJAPAN_EL_R「2026_西日本小学生大会_雨」)。参加者は同じで、試合の形式だけが違うので、大会を複製して作り分け、当日の天気で使う方を選ぶ。

## 正式な組み合わせ表の形(第20回西日本小学生ソフトテニス選手権大会 男子個人戦)

- 108組を、3組ずつの36ブロックに分ける。各ブロックでは「2番対3番の勝者が、1番と対戦」する。
- ブロックの勝者も、同じ「3つで1組」の形で戦う(例: 「ブロック2の勝者対ブロック3の勝者」の勝者が、ブロック1の勝者と対戦)。これが積み重なる。
- 用紙1ページに18ブロック(54組)。左右に9ブロックずつで、それぞれの勝者が戦ってページの勝者になる。2ページの勝者同士で決勝。
- 全体としては、**1つの大きなトーナメント表**の中に、ところどころ「不戦(1回戦がない枠)」を入れて、「3つで1組」のまとまりを作った形。

9ブロックの中の正式な形(数字はブロックの番号):

```
├ 1 対(2対3の勝者)
├ 4 対(5対6の勝者)  ┐
└ 7 対(8対9の勝者)  ┘ この2つの勝者同士が対戦し、その勝者が上の組の勝者と対戦
```

## 今のアプリでできないこと

- トーナメント表を作る処理(`services/stage_setup.py` の `generate_tournament_bracket_matches`)は、枠の数を2の累乗(8・16・32・64…)に切り上げて、空いた枠を**標準のルール(強い順に不戦を割り当てる)**で不戦にする。**不戦の位置を指定できない。**
- そのため、上の「3つで1組」の形は作れない。
- 試しに作った「2026_西日本小学生大会_雨」の男子個人決勝(36組。予選36個のトーナメント表の勝者が入る)を確かめた結果:
  - ページ・左右の区切り(9・9・9・9)は正式な組み合わせ表と一致している。分割表示を2つにすると、各ページの形に近い見た目にもなる。
  - しかし、**9ブロックの中の組み合わせが違う**。今の作りでは「1対(2対3)」「4対5」「6対7」「8対9」となり、例えば予選4の勝者が、すぐに予選5の勝者と当たる。正式には、予選4の勝者は不戦で、5対6の勝者を待つ。
  - 分割表示の設定は見た目だけを変えるので、組み合わせは変わらない。
- **この状態で雨の大会に使うと、正式な組み合わせ表と違う試合が組まれる。**

## 解決の方向(案)

根本の解決は、**「不戦(BYE)の位置を指定してトーナメント表を作れる」ようにすること**。トーナメントの試合のデータ(`TournamentMatch.next_match` / `next_slot`)は、もともと任意の木の形を表せる。また、不戦は「S」試合として扱う仕組みがある。そのため、変える必要があるのは主に、試合を作る処理と、枠の指定の入口になる見込み。

作り方の候補:

| 形 | 内容 | 良い点 | 気になる点 |
|---|---|---|---|
| ① 108組で1つのトーナメント表 | 予選のブロックも、その表の1回戦・2回戦として扱う。分割表示で4つ(各ページの左右)に分ける | 正式な組み合わせ表とまったく同じ形。進出元の設定がいらない | 大きな表になる。SVGの描画・印刷の確認が必要 |
| ② 予選36個+決勝36組の表 | 今の「_雨」の形のまま、決勝の不戦の位置だけを指定する。分割表示で2つ(各ページ)に分ける | 今の作りを活かせる | 全体を1枚の表としては見られない |
| ③ 予選36個+決勝18組×2+最後の決勝 | ページごとに表を分ける | ページと表が1対1 | Stageと進出元の設定が増える。②の分割表示で同じ見た目になる |

不戦の位置の指定方法の候補:

- Stage枠CSVで、枠ごとにドロー上の位置(1〜2の累乗)を指定する。指定のない位置を不戦にする。または、`BYE` の行を書く。
- 画面で、ドロー上の位置に枠を置く。

## 決めること(再開するとき)

1. 組み合わせ表はどう作っているか(Excelで作ってCSVで読み込むか)。不戦の位置をCSVで指定するか、画面で指定するか。
2. ①と②のどちらにするか(Claudeのおすすめは①。正式な組み合わせ表と同じ形で、印刷・掲示できるため)。
3. いつまでに必要か。
4. SVGの描画(片山表示・両山表示・分割表示)と印刷(トーナメント印刷のまとめ方・縮尺)で、不戦の多い表が崩れないこと。
