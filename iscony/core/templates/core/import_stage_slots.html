CSV仕様

カンマ区切りCSVとタブ区切りCSVの両方を読み込めます。 形式(stage_type) は L または T、進出元の種類(source_type) は LR または TR を指定します。

CSVに含まれるStageだけを置き換えます。初回はCSVでの登場順をStageの表示順とし、 再取込では既存Stageの順番を維持します。新しいStageはカテゴリ内の末尾へ追加します。 リーグとトーナメントは各Stage内での登場順になります。

ステージコード(stage_code)は任意です。空欄の場合はアプリがSTG1、STG2のように自動発番します。 既存のステージコード(stage_code)を指定して異なるステージ名(stage)を読み込むと、同じStageの名称を変更できます。 進出元ステージコード(source_stage_code)を指定すると、進出元Stageも名称に依存せず参照できます。

列名 内容
カテゴリ名(category) / ステージコード(stage_code) / ステージ名(stage) / 形式(stage_type) カテゴリ、任意のStageコード、ステージ名、L/Tです。
リーグ名(group) / トーナメント名(bracket) Lではリーグ名(group)、Tではトーナメント名(bracket)を指定します。
枠名(slot_label) / 表示順(display_order) 枠名と表示順です。
開始回戦(start_round)（任意・Tのみ） 各組が最初に試合をする回戦。列なし・全行空欄なら自動で組みます。 指定する場合は同じブラケットの全行に1以上の整数を入れてください。 開始回戦1=1枠、2=2枠、3=4枠…として数えます。 上から3組で1組目がシードなら、各行に順に 2,1,1。 16枠で1組目が3回戦からなら 3,1,1,2,…。
番号(entry_code) 参加者を直接入れる枠で使います。
進出元の種類(source_type) LRはリーグ順位、TRはトーナメント結果です。
進出元ステージ名(source_stage) / 進出元ステージコード(source_stage_code) / 進出元リーグ名(source_group) / 進出元順位(source_rank) LRで使用します。進出元ステージコード(source_stage_code)を指定した場合は、進出元ステージ名(source_stage)より優先します。
進出元ステージ名(source_stage) / 進出元ステージコード(source_stage_code) / 進出元トーナメント名(source_bracket) / 進出元マッチコード(source_match) / 進出元マッチの勝敗(source_result) TRで使用します。進出元マッチの勝敗(source_result)は win または lose です。同じステージ内にM1が複数ある場合は進出元トーナメント名(source_bracket)が必要です。
